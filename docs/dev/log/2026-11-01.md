# 2026-10-29 to 2026-11-01

Releases 0.1.8 to 0.1.12, all pre-releases from `development`. New work lands on `experimental` first and is merged into `development` for a release.

- 0.1.8: one shared hover/pressed/selected style for panes, menu and ribbon; Chat and Settings tabs in the assistant panel; the separate AI menu entry dropped; power-saving mode while minimized; Simplify keeps at least four faces.
- 0.1.9–0.1.10: silhouette-only selection outline from a cached mask; no idle repaints, smaller GPU heaps and a 60 fps cap instead of V-Sync; Windows exe icon.
- 0.1.11: Measure tool with arrow markers and a live distance bar; Split with a movable, rotatable cut plane and a clipped live preview; Smooth with a live preview; Material tool (none, simple, realistic, translucent, eyedropper); Texture tool (procedural textures and stencils, stickers, brush, QR, picture and camera sources). Face textures and colours survive split, booleans and smooth.
- Refactors: `render` and `viewport` split into module folders, actions and launch options out of `app/mod.rs`, emboss outlines in `emboss/outlines.rs`, shared Apply/Cancel checkpoint for interactive tools.
- 0.1.12:
  - Slicers: detected also as Flatpaks; printer, print and filament profiles read from the slicer's config (read-only, off the UI thread). The 3MF sent to the slicer carries the printer, the print profile and a filament per object and painted face.
  - 3D printer status window: the slicer's printers with live Moonraker state, every 5 s. The online print service and the Order online, Rate this app and Feedback menu entries were removed.
  - About the model: 3MF metadata editor; the window title follows the model title.
  - Print on paper with the system's own print dialog (XDG portal on Linux).
  - One drop-down component everywhere (list below the field, without the current choice); a clear × in focused text fields; the scene's colour list cached instead of rebuilt each frame.
  - AppImage package (glibc 2.31 via cargo-zigbuild). Packages are built locally with the scripts in `packaging/`.
  - Hotfix: the AI assistant button stays in the top bar when the assistant is off and opens on its Settings tab.
- State: 329 tests pass; fmt and clippy clean. Screenshots in `docs/screenshots/` retaken for this state, in English and with English file names, like the docs.

## MCP print tools (branch `mcp-print-tools`)

- New MCP tools: model_info, print_setup, printer_status, print_on_paper, in `src/app/agent_print.rs` and `print_tools()` in `src/mcp.rs`. They reuse the UI's code: `set_model_info` (About panel's Update), `take_profiles` (the print view's profile reading, now also blocking for the agent), `connected_printers` and `read_status` (status window; printers are now asked in parallel).
- print reads the slicer's profiles first when the print view has not, so the 3MF carries the printer, process and filament slots.
- Checked live over `--mcp` with a temporary config and data folder: metadata set, saved, reopened; profiles listed and chosen; printer status read. print and print_on_paper were not called.
- MCP tools for modelling and paint (`src/app/agent_model.rs`, `model_tools()`): paint_area, set_material, apply_texture, import, load_image; insert_shape with size and Custom, split with a slanted plane, emboss_text with every Emboss option. Both tool sets were merged into `experimental` and smoke-tested together over `--mcp` (24 tools); 361 tests pass.
