# 2026-11-17

## Assistant: screenshots from any angle

- The MCP `screenshot` tool takes `view` (front, back, left, right, top, bottom, iso) or
  `azimuth`/`elevation`, `focus` (`"all"`, `"selection"` or object ids), `isolate` and
  `size`. With any of them it draws the scene off screen on a thread (`app/agent_shot.rs`,
  with the CPU renderer of `thumbnail.rs`, now `render_view` with a `View`), so it never
  moves the user's camera or selection and works while minimized. Without them it still
  captures the window. Azimuth 0 is the starting camera's front (-Y).

## Arch Linux package

- `packaging/arch/PKGBUILD` (release tag) and `packaging/arch/build-pkg.sh` (local
  checkout, generic x86-64 flags) make `dist/buildcraft3d-<ver>-1-x86_64.pkg.tar.zst`.
  A pacman install is `PackageKind::Other`, so the updater opens the release page.
