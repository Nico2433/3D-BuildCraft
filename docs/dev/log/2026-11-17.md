# 2026-11-17

## Assistant: screenshots from any angle

- The MCP `screenshot` tool takes `view` (front, back, left, right, top, bottom, iso) or
  `azimuth`/`elevation`, `focus` (`"all"`, `"selection"` or object ids), `isolate` and
  `size`. With any of them it draws the scene off screen on a thread (`app/agent_shot.rs`,
  with the CPU renderer of `thumbnail.rs`, now `render_view` with a `View`), so it never
  moves the user's camera or selection and works while minimized. Without them it still
  captures the window. Azimuth 0 is the starting camera's front (-Y).

## Arch Linux package

- `packaging/arch/PKGBUILD` (release tag) and `packaging/arch/build-pkg.sh` (local
  checkout, generic x86-64 flags) make `dist/buildcraft3d-<ver>-1-x86_64.pkg.tar.zst`.
  A pacman install is `PackageKind::Other`, so the updater opens the release page.

## Antigravity no longer opens with the app

- Detecting agents ran `antigravity mcp list`, which starts the Antigravity editor. Its
  registration is now read from `~/.gemini/antigravity/mcp_config.json`; the app never
  runs `antigravity`. The other agents' `mcp list` commands are CLI only.
- OpenCode's switch came back off on every start: `opencode mcp list` shows names and
  states but no URLs, so the registration always read as outdated. OpenCode's
  registration is read from `~/.config/opencode/opencode.json(c)` too (the host's, also
  from the Flatpak).

## Cleanup before 0.1.16

- `camera::orbit_dir` is the one yaw/pitch → direction formula (orbit camera and
  off-screen views); `host::home` replaces the scattered `HOME` lookups.
- The agent's screenshot routing is one `App::screenshot` method.
