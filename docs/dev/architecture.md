# Architecture

## Components

The library crate (`src/lib.rs`, no UI) holds the core; the binary adds UI and rendering.

| Module | Responsibility |
|---|---|
| `src/mesh.rs` | Indexed mesh, optional per-triangle `colors` (RGBA; alpha 0 = object colour; edits that rebuild a mesh, such as booleans, repair, cut and simplify, drop them), `face_region` (flood fill across edges whose angle is under 5° + coverage·85°; coverage 1 = whole object), welding, normals, AABB, transform, topology stats (same counters as `stlstats.py`), ray tests; `Mesh::shading(40°)` splits vertices at creases (flat faces stay flat) and returns crease edges |
| `src/primitives.rs` | The 9 shapes at 40 mm, on the floor; cylinder matches the original's 240 vertices / 476 triangles. `custom(shape, lat, lon, width, height)`: box as a lat/lon cell grid, lon segments for round shapes, lat for box/sphere/torus; centred on the floor, proportions kept across |
| `src/io/` | `stl`, `obj`, `ply`, `threemf`, `gltf_io`: read and write with the original's conventions. `ModelInfo` (title, designer, copyright, license terms, description) is read from and written to the 3MF metadata |
| `src/scene.rs` | Objects (shared `Arc<Mesh>` + translation/rotation/scale + colour), selection, settle, duplicate, mirror, cut, simplify, resize, palette |
| `src/history.rs` | Undo/redo by snapshots (cheap because meshes are shared), 100 steps |
| `src/settings.rs` | TOML settings, 24 recent files, autosave to `<data>/AutoSaveFiles/{uuid}.buildcraft.3mf` |
| `src/camera.rs` | Orbit camera, Z-up, rays and projection; default pitch 30°, frame margin 1.9 |
| `src/render/` | wgpu pipelines (solid, x-ray, wireframe lines, checkerboard floor) in an egui paint callback; GPU meshes cached by `Arc` pointer. Look of the original: selection washed pale blue with crease-edge outline, soft shadow quad, mirrored reflection under a floor at 88 % opacity, light from front left |
| `src/texture.rs`, `src/texture_gen.rs` | Paint > Texture. `texture_gen`: 24 repeating textures (paper, linen, denim, burlap, water drops, crumpled paper, sandstone, gravel, three marbles, granite, plasters, felt, pearl, cork, three woods) and 6 white stencils, all procedural noise/polygons (no assets). `texture`: a grow-only registry gives each picture a layer number (max 64, 256 px square; files, camera frames and QR codes are squared into it); `Mesh::tex` holds a `FaceTex` (layer, sticker flag, 3 UVs) per triangle, kept by `transformed`/`flip`/`append`/`sub_mesh` and lost, like `colors`, by edits that rebuild the mesh; `apply_decal` (sticker: planar projection along the hit normal, per-pixel clipped in the shader) and `apply_box` (brush: box mapping per face along its dominant world axis). `render.rs` adds UV + packed layer per vertex, one `texture_2d_array` with mips (group 2, solid and x-ray pipelines only) and a live sticker preview uniform. Textures are not saved in files: `Object::to_model` paints tiled faces with the picture's average colour, stickers are dropped |
| `src/app/` | egui UI styled after the original ([ADR-0003](decisions/ADR-0003-ui-copies-the-original.md)). `mod.rs`: state, `Action`s (applied after drawing), shortcuts, screenshot options. One file per area: `top_bar` (own title bar, decorations off, edge resize via `BeginResize`; tabs), `ribbon`, `tool_bar` (replaces the tabs while a tool is open: split, simplify, hollow, emboss, measure, Color paint, import units), `side_menu` (left menu; Settings and recent files as panels beside it), `selection` (strip with vertical title; tiles per object, stats in tooltip), `transform` (bottom bar fields with green/blue strip, a click makes a field current (green), a click on the current one opens the editor above the bar (Enter or Accept applies, Escape or a click elsewhere cancels; one undo step per value); strips fade up into the bar; rotate shows Roll/Pitch/Yaw, "deg." and a reset orientation button; scale has an underlined unit that switches to percent of the unscaled size (rotation and translation kept, scale 1); emboss size/depth/angle/offset live here), `viewport` (distance labels, handles from `gizmo` (one undo step per drag); Custom draws its grey preview first in front of a see-through scene, wireframe toggle), `start` (start screen while the scene is empty and nothing was picked: logo, More information, New scene, Open, last three files; hides tab selection and ribbon), `dialogs` (`black_box` draws the original's black question boxes: unsaved changes and recover; notices as cards; running jobs on top with a progress bar and a close button), `jobs` (loading files from the UI and repairing run on a thread; `Done` comes back through a channel and is applied by `collect_jobs`; repair skips objects whose mesh changed meanwhile; the bar shows steps done, or eases towards 90 % with time for loads; the agent calls `wait_jobs` so it answers after the work), `add_dialog` (modal Add: recent files as thumbnail tiles, Load object, Load image with size/depth/mode/invert and a preview that rebuilds when a drag ends; Camera opens the live webcam picture (`src/webcam.rs`, nokhwa, frames on a thread) and Capture sends it to Load image; the 3D library browses folders the user adds as libraries, saved in `Settings::libraries`, listed on a thread, removed by right-click; `--library dir` shows one without saving it), `thumbs` (background thread that renders thumbnails for recent files, library items and selection tiles; disk cache in the cache dir keyed by path + mtime; up to 600 in memory; jobs from an old page are skipped by generation), Color tool with a Coverage slider (paints the `face_region` under the click), `print` (3D print view replacing tabs, ribbon and panels: nav Printer/Material/Design/3D printer status/About; Printer lists the slicers `src/slicer/` finds or one picked by hand, with the slicer's printer and print profiles; Print saves the scene as 3MF with the chosen printer, print profile and a filament per object and painted face, and opens it there; Material maps each scene colour to a filament slot of the chosen printer (colours fully covered by paint are hidden); Design sets units, scale %, width/height/depth and resets orientation/scale via `Scene::scale_all(k)`, uniform about the footprint centre, one undo step per edit from the size at its start; About shows objects, triangles, size, volume; black bar with cost not available, warnings for invalid or floating objects, undo/redo, Print, Cancel. 3D printer status is a window with the slicer's printers and their live state; `SceneColors` caches the scene's colour list by mesh; view buttons). `agent` (runs tool calls from the chat, stdio MCP or the local port through `apply`, see ADR-0004), `assistant_ui` (Menu > AI assistant page and the chat panel; `src/assistant.rs` holds the endpoint/agent loop), `gizmo` (selection handles fixed in 3D: move arrows, rotate rings (a drag turns by the angle swept round the ring centre on screen, summed frame by frame, about the world axis through the selection centre; rings seen nearly edge on fall back to sliding along the tangent), scale box; the hovered or dragged one is green; objects move only through them; one click selects, double click centres the view; pressing on the selection and dragging slides it on the floor; move cursor over handles and the selection). `texture_ui` (Texture tool: Selected menu with Load, Texture picker, Camera, QR, recents, grid and stencils; Sticker mode previews under the pointer and a click bakes it as one undo step; Edit sticker lifts the last one to drag/scale (wheel)/turn (Shift+wheel); Brush mode paints the face region under the pointer, a drag is one undo step; `--tool texture|texture-menu|texture-sticker|texture-edit|texture-brush`). `style.rs`: colours sampled from the original, shared widgets (`dropdown`/`list`: every drop-down in the app, the list opens below the field without the current choice, above it when there is no room, scrolls past 12 rows; `text_field` with a clear × while focused; `unit_field` with a dimmed unit inside, `slider` with an upright handle and ticks), sizes in points from its 150 % screenshots (title 32, tabs 48, ribbon 48, tool bar 60, strip 45, menu 204, flyout 296); | `src/slicer/` | `detect` (installed slicers, native or Flatpak, and opening a 3MF in one), `profiles` (printer, print and filament profiles read from the slicer's config folder, read-only, off the UI thread), `host_files` (reading those folders from inside the Flatpak sandbox in one host call), `status` (printers configured in the slicer and their state from Moonraker over HTTP, port 7125, every 5 s on a thread; read-only queries). Access codes and API keys found in the profiles are never shown or logged |
| `src/paper.rs` | Print on paper: a picture of the model, a one-page A4 PDF (JPEG, hand-written), and the system print dialog: the XDG desktop portal on Linux (`ashpd`), the picture's print verb on Windows. `src/app/paper.rs` runs it as a job |
| `src/host.rs` | Running programs on the host when the app is in a Flatpak (`flatpak-spawn --host`) |
| `src/assistant.rs`, `src/mcp.rs` | The in-app assistant (chat with an OpenAI- or Anthropic-compatible endpoint, or an installed agent) and the MCP server (JSON-RPC over stdio or a local port) with the app's tools; see [ADR-0004](decisions/ADR-0004-ai-agent-can-drive-the-tools.md) |
| `src/webcam.rs` | Camera frames read on a background thread (Add > Camera, texture camera source) |
| `src/snapping.rs` | Bounding-box edge and centre alignment while moving, with guides |
| `src/library.rs` | Local 3D libraries: `list` (subfolders that contain models, then models) and `search` (by name, depth 8, sorted then capped at 500 results) |
| `src/thumbnail.rs` | CPU rasteriser for thumbnails: 2× supersampled, per-face colours, no GPU |
| `src/image3d.rs` | Load image: Relief (height map, dark is high, 0.6 mm base, at most 160 samples a side, optional invert) or Outline (dark part traced with Emboss's image tracing and extruded) |
| `src/repair.rs` | Mesh repair: weld, drop degenerate/duplicate faces, remove stray faces on odd non-manifold edges and unfixable folds, split vertices where surfaces touch along an edge, orient, fan-fill holes (splitting pinched boundaries); repeats until clean |
| `src/cut.rs` | Plane cut "Dividir": horizontal plane only; caps by earcut with holes found by contour nesting; keep top, bottom or both |
| `src/boolean.rs` | Booleans "Combinar/Intersecar/Restar" via manifold-rust; Restar with one object selected cuts it out of every object it overlaps and removes it (`App::subtract_selected`, objects whose shapes do not really meet stay untouched); with more it subtracts newer selected objects from the oldest. Either way pieces left apart become separate objects through `Mesh::solids` (shells by shared vertices; inward shells, i.e. cavities, stay with the smallest solid whose box holds them) |
| `src/solid.rs` | Smooth (`smooth_out(60°)` + `refine(2)`, refused above 250k triangles), Hollow (voxel inside/outside, exact distance transform, `Manifold::level_set`, inner solid subtracted), Extrude down (skirt per downward patch, unioned, trimmed at the floor), `round` (Custom roundness 0–10: `smooth_out` + `refine(4)`, fitted back into the original box, capped at 60 000 input triangles); via manifold-rust |
| `src/emboss.rs` | Emboss "Relieve". Patterns: text (bundled Ubuntu Light or any installed family via `fontdb`, loaded once), star, heart, circle, or a PNG/JPEG traced by marching squares at up to 256 px (dark opaque pixels; last trace cached by path and mtime). Outlines are filled (`cut::fill`) and refined; each point is a ray onto the object, first hit found among triangles binned by the inverse mapping (only those near the pattern). Projections: planar (from above), cylindrical (towards the vertical axis through the bbox centre, front −Y, offset.x = arc length; seam kept opposite the pattern), spherical (towards the bbox centre; corners on the axis take their neighbours' azimuth). Bevel: border starts at 1/3 of the height and rises over 4 % of the size, fine points only along the outline. Colours: body plus a top layer of min(0.4 mm, depth/4); a layer with its own colour becomes a separate object with its sides trimmed by subtracting the object; engrave ignores colours. Solids are unioned with or subtracted from the object via Manifold. `offset_at` maps a surface point to a pattern offset (drag to place, Shift+drag to turn) |
| `src/i18n.rs` | UI languages: `Lang` (Spanish, English); UI text is English in the code, `tr(lang, en)` looks it up in the Spanish table `ES`; default from the OS locale; test fails when a key in any file of `src/app/` has no Spanish entry |
| `examples/inspect.rs` | CLI: object list and topology stats of model files; `--repair` repairs first and reports the result |

Other pieces in `src/`: simplify "Simplificar" uses `meshopt` (wireframe is shown while the tool is open); `src/io/` shares helpers (`unique_colors`, `fan`, one PLY loop, `xyz_fields`); the shortcut table and `add_copies` live in the app and scene code.

Dependencies for geometry: `meshopt` (simplifier, built with `cc`), `manifold-rust` 0.19 (pure Rust port of Manifold, see [ADR-0001](decisions/ADR-0001-booleans-with-manifold-rust.md)), `earcutr` (cut caps), `epaint_default_fonts` + `ttf-parser` (Emboss font; both were already in the dependency tree), `fontdb` 0.24 (installed fonts), `image` 0.25 with PNG/JPEG only (Emboss images; already in the tree).

Screenshots of a known state: `cargo run --release -- --screenshot out.png` with `--size`, `--zoom`, `--tab`, `--tool`, `--lang`, `--select-all`, `--menu`. App captures are in `docs/screenshots/`; reference photos of the original are kept outside the repository.

## Data flow

1. A file is read by `io::load` into `ModelObject`s (mesh in object space + transform + colour).
2. Unitless formats (STL, OBJ, PLY) open the import dialog for units; 3MF and glTF convert on read.
3. Objects enter the `Scene`; open or non-manifold meshes are flagged and drawn with a red box.
4. Each frame the UI builds `DrawItem`s (per-vertex colour when a mesh has triangle colours); `FrameCallback::prepare` uploads new meshes and per-object uniforms; `paint` draws.
5. Edits go through `App::edit`, which stores a snapshot for undo; the autosave writes a 3MF every 60 s while dirty and is removed on clean exit.
6. Saving goes through `io::save`; 3MF keeps placement in the build transform and writes triangle colours as per-triangle `pid`/`p1` (read back on load); the other formats bake placement. The 3MF save is atomic (temp file, then rename), which also protects the autosave.
7. The repair prompt (open or non-manifold meshes) runs `repair`; the tools cut, simplify, booleans, Smooth, Hollow, Extrude down and Emboss take the selected objects' meshes and return new ones, applied as one undoable edit.

## Integrations

- Slicers: opened as a host program with a 3MF; their config folders are only read.
- Printers: Moonraker HTTP status queries (read-only), through the hosts the slicer has configured.
- AI: model endpoints over HTTP, local agents through MCP ([ADR-0004](decisions/ADR-0004-ai-agent-can-drive-the-tools.md)); keys in the system keychain.
- Print on paper: the XDG print portal on Linux.
- Native file dialogs through `rfd`; config and data folders through `directories`.

## Hubs

`Scene`/`Object`, `Mesh` and `io::ModelObject` are what every part touches.

## Risks and constraints

- Picking is a brute-force ray test per triangle; fine on click, slow for drag-hovering big meshes. A BVH is still missing.
- egui 0.31 is pinned on purpose; upgrading needs API changes in `src/app/` and `render.rs`.
- Repair result on the camel sample (1.39M triangles; 20 open, 20 non-manifold, 24 misoriented edges before): none after, volume change 1e-5 % (original app 1.6e-3 %), +8 vertices (original +16).
- Booleans depend on manifold-rust, a young pure-Rust port; inputs must be repaired first.
- Open limits (found in review, not fixed):
  - One colour per object on import (PLY first vertex colour, glTF first primitive material); 3MF per-triangle colours are kept (`Mesh::colors`); other formats still get one colour.
  - OBJ/PLY polygons are fan-triangulated, so concave n-gons come out wrong.
  - The cut plane is horizontal only (no rotation).
  - Not implemented: saving textures in files, slicing and sending jobs from the app (the slicer does it). Printer status speaks Moonraker only.
  - Area paint is lost by any edit that rebuilds the mesh (booleans, repair, cut, simplify, smooth, hollow, emboss).
  - The thumbnail disk cache is never pruned.
  - Emboss limits: the cylinder/sphere axis is the bbox centre (the user cannot choose it); very thin objects (radius < 0.5 mm) may give a self-intersecting solid; image detail is capped at 256 px; one colour per object part (no per-face colour).
  - Emboss on the camel (1.4M triangles): preview 77–136 ms, 130–220 ms with bevel (UI thread). The orange preview is keyed to the selected object's id, mesh and transform, so undo or a selection change rebuilds it.
  - Solid edits (`src/solid.rs`) run on the UI thread with no progress or cancel. Smooth: camel (1.4M triangles) took 5 s, hence the 250k cap. Hollow: voxel = max(wall/4, longest side/160) and the inner surface is pulled in 2.7 voxels, so big models get thicker walls than asked (camel at 1 mm: ~4 mm wall, 2.7 s); Minkowski erosion was rejected (5 s on a 6k-triangle torus, minutes on the camel). Extrude down: ms on ordinary models, ~50 s on the camel (7,874 patches); a patch whose projection overlaps itself (underside of a helix) gives an invalid skirt.
- Release packages (MSI, zip, Flatpak, AppImage) are built locally with the scripts in `packaging/`; the GUI itself has been run on Linux and the Windows build in Wine only.
- Library error details (`src/io/`, `src/boolean.rs`, `src/solid.rs`) are English only, also in the Spanish UI.
